# fastforks overview: all models, one table

Every row compares the same four tiers on one RTX 5060 Ti 16 GB (torch 2.14.1+cu130; measurements dated 2026-10-10 to 2026-10-24, see each repo's README for the exact date).

- **upstream**: the unmodified model as released (fp32, or the upstream default precision where upstream already runs fp16/bf16 autocast; noted per row).
- **upstream + flags**: the same code with driver-side switches only (inference_mode, cudnn.benchmark, TF32, fp16 autocast or `half()`, channels_last). **Every speed-up in this table is relative to this row.** The only exception is the separate column "cuda-kernels vs upstream".
- **portable** branch: plain PyTorch only, exports to ONNX / TensorRT like the original. **cuda-kernels** branch: descends from portable and adds custom CUDA kernels / fast paths (no ONNX export). `main` mirrors upstream.
- `-` = this tier does not exist for the repo; `n/m` = not measured. Speed-ups are computed from the ms columns, 2 decimals. Peak MB = torch peak allocated.
- Reference setting: Middlebury-H Motorcycle 1482x994 for stereo and depth repos unless named otherwise (largest or main setting listed in the README); `A`/`B` sizes that a README does not spell out are marked as such.
- Bundles: **fast-vision-models** has no tier branches (the tier is a function argument); one row per model, setting = the one with the highest upstream time. **fastbb** is a kernel library with a friendly/max table (friendly = portable slot).
- Gaussian-splatting training libs (gsplat, fused-ssim) have no flags tier and report training time / loss time instead of inference ms (unit in the cell).
- Quality columns differ per task and are named in the cell; "(portable)" means the second value is the portable tier because the repo has no cuda-kernels row.
- Caveats per repo (not like-for-like precision, OOM, column anomalies) are in the notes column and in `overview_inconsistencies.md` of the publishing workspace.
- Excluded: the private `*-private-backup-*` repos.

Regenerate with `make_overview.py` (publishing workspace).
